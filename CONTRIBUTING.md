# Contributing

Thanks for wanting to help. Bug reports and small fixes are very welcome.

1. **Open an issue first** for anything bigger than a small fix, so we can agree on the approach.
2. **Accept the [CLA](CLA.md)**: a bot will ask you to sign by posting one comment on your first pull request. It lets the project keep a single, clear license for all the code, including commercial licenses (see [COMMERCIAL.md](COMMERCIAL.md)).
3. Keep changes focused, add or update tests where it makes sense (`cd src-tauri; cargo test`), and keep the UI texts in both languages (`src/lib/i18n.svelte.ts`).
4. By contributing you agree that your contribution is released under the project license, [PolyForm Shield 1.0.0](LICENSE).

The project name and logo are not part of the license: see [TRADEMARK.md](TRADEMARK.md).
