## How to accept
Open your pull request. A bot will ask you to sign. Reply with exactly this comment:

> I have read the CLA Document and I hereby sign the CLA

The bot records your GitHub account, the date and the pull request in `signatures/cla.json` (on the `cla-signatures` branch). You only need to do this once. This version of the agreement is **CLA v1.0**.

Pull requests without a signature will not be merged.
